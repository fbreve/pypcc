# Frozen protocol: undirected split vs single bridge vs full canonical kNN

Written **before measuring any native PCC outcomes**. Branch `experiment/numpy-undirected-bridge-disconnect-v1` derives from validated but unmerged draft #184 HEAD `832e4779f17332a2cdc11c76506939db6b822931`, and hence depends on experimental #183/#182. Nothing is merged or changed in `master`. This does not repeat the PR #184 k=3/k=10 study or the old noncanonical *directed* lockout cohort.

## Scientific question and deliberate construction

On real standardized sklearn **Digits (1797 vertices, 10 classes)**, what happens to accepted particle mobility, possible class-level lockout, crossover, and held-out classification if an undirected graph has **two components** or **one narrow bridge** instead of the ordinary connected union-10NN graph?

- Three strictly undirected, reciprocal, loop-free, deduplicated variants:
  1. **full_union10**: untouched production `pcc_graph.build_knn_graph(X,k_nn=10)` on *all* standardized Digits rows.
  2. **split_disconnected**: deterministic partition by **original vertex index parity** (899 even vs 898 odd), independently call **the identical official production builder** `build_knn_graph` on each standardized half, remap edges to global vertex IDs, then construct undirected union via original `build_graph_from_edge_index`. No cross-partition edge; demand exactly **two connected components**, sizes **899 and 898**, each internally connected and min degree >=10.
  3. **single_bridge**: take **exactly the split graph edge set** and add **one undirected cross-partition edge** whose endpoints minimize squared feature-space Euclidean distance between the two halves (stable index tie break). Demand exactly **one connected component**, exactly two additional directed arcs compared with split, exactly one partition-crossing undirected edge, and no other edge changes. Both sides retain the identical within-component graph used in the disconnected arm.
- Full graph and split graph have different internal neighbor sets because neighbor search is restricted to each half; thus full-vs-split is **not** a one-edge causal contrast. The isolated **split-vs-bridge** contrast is exactly one reciprocal edge; record all three degrees, edge counts, component sizes, labels and the cross-edge ID. The partition is artificial and unrelated to class (all ten classes must be represented on each side); we do **not** assert this is how typical kNN graphs disconnect in real applications.
- Freeze **4 new independent seeds `(21107,21221,21317,21401)`**, distinct from #184. Select **one initially labeled vertex per class in each partition**, independently with `np.random.default_rng(seed)`; exactly **20 particles**, two per class, each class guaranteed a home on both sides. All three graph arms use exactly the **same** selected labeled vertices within each seed, avoiding trivial inaccessible classes in the disconnected graph.
- Native PyPCC **sequential NumPy** only: `p_grd=.5,delta_v=.1,deltap=1,dexp=2,max_iter=100000,early_stop=False`. Fixed 100k horizon is **not** convergence. Each of **12 seed×graph cases** has two fresh native fits: truly ordinary unobserved and **one uninterrupted every-physical-iteration observed** fit; **24 real fits**, 4 Linux/Python3.12 seed matrix jobs, 1 independent mandatory 12-case summary. Alternate fit order; never omit cases.

## Frozen measurements and gates

- Reuse the verified experiment-only `MobilityObserver` from #184 (no changes to it). Its 100001 unique physical callbacks, 100×1000-step windows per class, class accepted-move counts, particle longest stationary streaks, zero-system-motion iterations, strength, current winning neighbors, mass and exact operational lockout rule are unchanged. **Lockout requires 5 consecutive zero-accepted-move 1000-step class windows, strength max <=0.01 and zero winning neighbor entries**. Isolated vertex count must be zero. All positions remain valid, and every physical particle iteration has a valid proposed neighbor.
- Extend only an **experiment-only** observer subclass with **per-step cross-parity move counter** (actual particle position parity changed). On split graph it must remain exactly zero, on single bridge every cross-parity change must traverse the **one registered bridge endpoint pair**; no assumption any crossing must occur. Count crossing moves per class, plus per-particle crossing totals.
- Require **bitwise parity** of all **six complete final arrays** (predictions, positions, strengths, distances, dominance, normalized ownership), **exact native stopping metadata**, all five NumPy MT19937 state fields and next 16 generated draws, true last raw ownership and no duplicate final physical callback, between the observer-enabled and ordinary fresh same-seed **same-graph** fits. No expectation of bitwise equality across different graph arms (their RNG draw histories can diverge).
- Report initially-unlabeled true-label accuracy across the same 1777 vertices for all 3 arms in a seed and **separately per parity partition**. Report full-vs-split and bridge-vs-split signed paired percentage point changes; these are descriptive (4 seeds, no statistical significance claim). Report lockout counts, class-window acceptance, longest stationary stretches, component counts, bridge crossovers, individual worst case rather than just means, and exploratory elapsed runtimes. Include full window details + dependency inventories in artifacts.
- **Synthetic tests** verify exact two-components/one-bridge edge invariants, class homes on both sides, no false crossing in disconnected graphs, a legitimate out-and-back crossing over a bridge, subclass callback completeness and finite state. A missing/duplicate seed×variant or parity divergence must fail the mandatory summary.
- No success/failure gate based on occurrence of lockout, accuracy difference or crossing count; both positive and null results are valid scientific data. Do not introduce particle reset, forced strength, movement modifications, new stopping rules or production graph defaults even if a rare case appears. Keep all dependent PRs **DRAFT/UNMERGED**.
