# Frozen protocol: nested undirected bridges, physical mixing and PCC accuracy

**Preregistered before any new outcomes.** This independent scientific study is a dependent **draft** based on validated but unmerged PR #185 head `6ee24b7dcc92db5958c464ac059c36a44984a003` (and #184, #183, #182). No production source, graph builder, model, kernel, movement, stochastic draw, potential stopping policy or high-level API will change.

## Scientific question and controlled graph contrasts

On standardized sklearn **Digits** with exactly 1,797 nodes and ten classes, measure whether increasing the number of *undirected* links between two artificial 899/898-node partitions increases **actual accepted cross-partition particle movements** and affects held-out accuracy, while **all internal edges and initial labeled nodes remain fixed**. A single bridge has already been shown in #185 to allow very little mixing; this experiment is a *new, fixed bridge-dose comparison*, not retuning early stopping.

Use the exact same partition by original vertex index parity and the same graph construction function as #185: official `pcc_graph.build_knn_graph(X[parity],k_nn=10)` separately for both parts, then symmetrize with official `pcc_graph.build_graph_from_edge_index`. On this dataset require the internal graphs to be connected, with no isolates, 899/898 vertices, all ten classes present in both parts, reciprocal undirected active edges, no duplicates/self-loops. This is an artificial topology stress test, **not** typical naturally disconnected kNN.

**Freeze bridge doses `B=(0,1,8,32)`** undirected edges; 0 is disconnected. All other internal edges are **identical**. Build a single deterministic ranked list of the first **32** cross-partition edges: order all cross-partition pairs by squared Euclidean distance in globally standardized feature space, ties by original row-major parity-side indices (`np.argsort(...,kind="stable")`). Greedily select a pair if **both endpoint vertices have never been selected before**; this disperses the bridges instead of concentrating all connections on one high-degree node. Nested conditions have exactly the first B bridge edges; the B=1 edge **must match** #185's unique global-nearest bridge. Each variant must have exactly B cross-partition undirected edges, with `2B` directed arcs, and no other changed edges. B>0 must yield one connected component, B=0 exactly two. Require 32 distinct endpoints per side and the ordered list to be **identical across seeds**. Report actual mean/min/max degree, component sizes and the selected edges; do not claim equal model randomness across different topologies.

Freeze novel seeds **`(22103,22229,22307,22441)`**, none included in #185. Exactly **one labeled home per class in each partition**, chosen by the existing unchanged `labelled_nodes(truth,seed)` helper from #185, for 20 particles total. Use exactly the **same** 20 labeled vertices across all four bridge doses **within each seed**. Graph and label sets remain semantically undirected, not directed kNN.

## Full-run controls and observations

- Native PyPCC sequential `impl="numpy"` only; `p_grd=0.5,delta_v=0.1,deltap=1,dexp=2,max_iter=100000,early_stop=False`. No early-stop policies tested. The 100k horizon is **a finite cap, not convergence**.
- **4 seeds × 4 bridge doses = 16 strict pairs / 32 independent real fits** (fresh ordinary unobserved and one true uninterrupted every-step observed per pair). Run 4 Linux Python 3.12 seed-matrix jobs, each with all four doses; rotate ordinary/observer run order. CI must require 4 distinct seed artifacts and a strict 16/16 aggregate, without missing, duplicated or silently excluded cases.
- Reuse #184's `MobilityObserver` and #185's true final-state/RNG validation **unchanged**. Add an experiment-only subclass that checks every real cross-parity position transition is on **one of the B permitted reciprocal bridge edges**; for B=0 **no crossings may occur**. Count **each true accepted crossing** per particle and class (including out-and-back within a 1000-step window), class-window crossing counts, first crossing iteration and number of particles that ever crossed. Count each full-step ordinary accepted movement by class, stationary streaks, zero movement windows, and strengths using existing collector. Check `sum(class crossings)=sum(particle crossings)=sum(window crossings)=total crossings`, and `crossings <= all accepted moves`.
- The inherited preregistered operational class-lockout condition remains **five consecutive 1000-step class windows with zero accepted movements**, current max class strength ≤0.01 and zero winning outgoing-neighbor entries. Retain all 100 × 10 per-class full-window records and native strengths, masses, accuracies, and mobility summary. Both zero and positive events are **valid scientific outcomes**, not pass/fail gates.
- Require **bitwise exact final-state parity** between observer/no-observer same-graph fits: all six full final arrays, native stop metadata, full NumPy MT19937 tuple and next 16 draws, and real final low-level unnormalized ownership state/RNG before high-level normalization. Require exactly **100001 unique physical callbacks** (0..100000) plus one genuine final notification, no replay of separately stopped prefixes.
- Report true-label accuracy on the **same initially unlabeled 1,777 nodes** across doses within each seed, plus by parity side, differences (1−0, 8−0, 32−0, 32−1) in percentage points, crossing counts, fractions of 2,000,000 attempted per-run particle steps, operational lockout and descriptive one-off timings. Always show **per-seed variability** and any nonmonotonic outcome. Do **not** require monotonic crossing/accuracy with B because the added edges also perturb transition probabilities, local dominance, trajectories and random stream consumption.

## Integrity gates and interpretation

Synthetic tests must verify exact nested edge sets/degree counts, unique bridge endpoints and reproduction of #185's one-edge bridge; true out-and-back crossing counts; an illicit crossing rejected; correct 1000-step class-window counters; duplicate/omitted callbacks rejected. Full scientific summary must fail if any of the 16 conditions, all four seeds, graph invariants, labeling or exact parity is missing. Archive raw per-seed JSON and dependencies and complete aggregated report. No adaptive choice of B, seeds, stopping criterion, labeled budgets or graph families after results.

**No merge, no reset, no strength floor, no change to production k or stopping rule** on the basis of this small same-dataset descriptive stress test. A dose-response tendency does not prove causal mediation through crossing counts or imply broader generalization. Full canonical union-10NN from #185 differs at many intra-partition edges, so it is *not* an equal-edge-dose control.
