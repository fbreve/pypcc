# Premeasurement resolution addendum: batched CPU clocks and bounded large-state allocation

Committed after the original protocol and BEFORE any candidate audit, CI or CPU result. The frozen original candidate, workloads, correctness conditions and GO/NO-GO thresholds remain unchanged.

- Python `time.process_time_ns()` on Windows has ~15.625ms quantization, so no individual submillisecond unique operation or 0-iteration fit is an interpretable CPU datum. Each microphase source CPU **pair** measures one **entire batch** of 2048 original/candidate evaluations for n<=1797 and 256 evaluations for n>=30000, reporting total ns and per-call ns (never measuring compilation of snippets). 25 alternating pairs per fixture per OS as frozen, and 5 separately traced peaks per fixture/OS. Measure no hashes, assertions or memory tracing inside CPU batches; do them after.
- Each full public original/candidate real sklearn CPU pair measures **4 independently initialized full fits** under one process CPU interval per source and records six final arrays/stop/RNG *after* interval. Two alternating source CPU batches per case/host, as frozen. Never pool raw OS times or treat technical repetitions as independent scientific labeled-mask seeds.
- Each large ring synthetic native original/candidate CPU pair measures **8 independently initialized 0-/5-iteration complete fits** under one process CPU interval per source, with two source-order-balanced CPU pairs per scenario/host. A single 100000×50 model can use around 80MiB for dominance+owndeg and 15MiB for distance tables; create models **sequentially, releasing previous arrays between fit calls**, rather than retaining eight sets simultaneously. Preserve complete output/state/RNG parity for every native fit and ensure an original Numba signature JIT warmup outside CPU timers.
- A single full dense control at 1024 and 1797 nodes ×50% labels ×two classes ×Numba max_iter=0 (1 paired batch/host) is intentionally small enough to avoid large particle distance tables. All unlabeled/single known classes on 100k nodes check the no-fit identity return and warning behavior without expensive native graph-level propagation; no object-identity shortcut for actual fitted results.
- All stopped/fixed native result checks distinguish `max_iter=0` (zero draws/no movement) and `max_iter>0`. Original native C/F memory layout and RNG should be compared after every batch, not only the last.
- The uninstrumented original production source is always the control: benchmark phase code is compiled directly from the two exact source blocks (not hand-implemented alternate algorithms). The source replacement is only one single guarded hunk. No attempt to leverage caching of class sets between different labels, which would be a separate potentially unsafe mutable API change.
- Both OS timed datasets and raw source class phase timings remain archived, including sparse and 50%-labeled controls. No invented performance improvement or threshold adjustments.

The batch clock technique is adopted before collecting any CPU data because of the known Windows timer granularity from experiments #220–#221.

## Before-data clock sizing refinement

A further nonexperimental clock-resolution audit confirms that a **4-fit Cython or 8-fit short ring 0-step batch may still fall below Windows' ~15.625ms process-CPU quantum**. Before any hosted run/data, supersede only batch sizes (not workload, source, repeats or frozen GO gates): real source pairs use **4 full NumPy fits, 32 full Numba fits and 64 full Cython fits per CPU interval**; each synthetic 30k/100k ring source interval uses **32 complete native fits**, and 1024/1797 50%-known controls use **128 complete fits**. Every case reports its actual `count`; original/candidate in the same cohort use the SAME count. This preserves exactly 192 real, 96 ring and 4 dense original/candidate CPU pairs across both hosts. No semantic test, source edit, memory budget, GO or regression criterion changes. This refinement precedes all external measurements and prevents a known instrumentation failure from wasting scientific CI work.
