# Preregistered cross-dataset generalization of undirected bridge-dose PCC dynamics

**Frozen before executing any new Wine/Breast Cancer PCC outcomes.** This scientific draft builds on unmerged #186 (and #185/#184/#183/#182). Does not change `master`, model/API, NumPy/Numba/Cython kernels, graph construction, particle movement, strength, RNG or production potential stopping.

## Research question

The previous Digits 0/1/8/32 reciprocal cross-partition bridge study found that adding bridges increased **actual particle crossings** but **did not reliably improve classification**, and did not exhibit operational whole-class lockout. Does that pattern generalize, at least descriptively, to two *different class counts and smaller real datasets*, on independently selected seeds? No new bridge-count tuning or reset. The experimental split deliberately creates a topology stress test, **not a natural disconnected data-generating process**.

## Frozen inputs (2 datasets × 4 seeds × 5 graph arms)

- Datasets: `sklearn.datasets.load_wine` (**178 nodes, 3 classes**) and `load_breast_cancer` (**569 nodes, 2 classes**). Standardize the **whole feature matrix** with `StandardScaler` as the canonical PyPCC experiments have done. Label vocabulary must be consecutive 0..C−1.
- Partition nodes by **original integer row ID parity** (Wine **89/89**; Breast Cancer **285/284**) — the same *rule* as the prior Digits study, not its graph. Each partition must contain **at least two ground-truth examples of every class**, be internally connected with original production `pcc_graph.build_knn_graph(features_of_partition,k_nn=10)` union-symmetric undirected edges, and have no isolate. This graph-connectivity precondition is validated and reported for each dataset; it was checked before outcomes, not filtered after sampling results.
- Build an exact **nested 0/1/8/32** reciprocal edge sequence across those two fixed components with **identical internal edges**. Rank every opposite-parity pair by standardized squared Euclidean distance (stable row-major tie order), greedily choose the next pair only if neither endpoint was used before (32 unique endpoints per side); each arm has precisely the first B edges. Require 0 → 2 components; B>0 → 1; no self-loop, directed missing reverse arc, duplicate or extra intra-component change. Bridge B=1 must be globally closest cross-partition pair, and 8/32 must be exact supersets. Record SHA-256 full graph edge fingerprints and the entire ordered 32-edge list, deterministic across all seeds within dataset.
- A fifth **descriptive-only** arm, `full_union10`, is built on the **whole** dataset using untouched `pcc_graph.build_knn_graph(X,k_nn=10)`. Require one connected component and complete reciprocity. This arm changes numerous within- and between-partition edges and **MUST NOT** be misrepresented as a one-edge causal contrast or a point in the controlled bridge-dose curve. Report its cross-parity edges and actual particle crossing counts separately.
- Preselected **fresh seeds (23111,23209,23321,23417)**, none used in #185/#186. Pick **one labeled node of each class in each parity partition** using `np.random.default_rng(seed)` and reuse exactly the same labeled nodes in all five graph arms within seed. Thus Wine has 6 particles, Breast Cancer 4; every class is initially present in both components and the disconnected graph cannot trivially lack a whole class's supervision on one side. Evaluate on the same held-out initially unlabeled nodes for all arms within dataset×seed, Wine **172**, Breast Cancer **565**.
- Native production `ParticleCompetitionAndCooperation(impl="numpy")` sequential dynamics, `p_grd=.5,delta_v=.1,deltap=1,dexp=2,max_iter=100000,early_stop=False,es_chk=2000` (early-stop unused). No force floor, reset, other propagation logic or per-run adaptive stopping. A fixed 100k reference is **NOT convergence**.

## Real native validation and metrics

- **2 datasets × 4 seeds × 5 arms = 40 conditions**, each with two fresh native propagations: (a) uninstrumented ordinary, (b) one uninterrupted actual per-iteration observed fit using the existing #184/#186 experiment-only streaming observer. Total **80 actual 100k native fits** and 40 genuinely continuous **100001** physical-iteration traces; 8 independent GitHub Actions matrix jobs (one dataset×seed) and a required full **40/40 strict aggregator**. Each dataset×seed job executes all five conditions, alternating observed vs unobserved order.
- The stream counts **accepted particle node changes on every physical iteration** (including out-and-back moves hidden from 1000-step endpoints), individual longest stillness streaks, accepted movements per class, whole-system no-motion steps; at exactly 100 nonoverlapping 1000-step windows per class, max/min particle strength, current class-winning outgoing neighbor count and initially unlabeled dominance mass. Hold the original operational class lockout definition: **five consecutive 1000-step zero-accepted-movement class windows, class max strength ≤0.01 and zero current class-winning outgoing neighbor entries**. This event is not evidence of irreversible absorption. The absence/presence of events is NOT a CI success criterion.
- Every true cross-parity accepted position change must occur along a **present allowed reciprocal cross-edge** for that arm. Record cross transitions per class, per particle, per edge and each 1000-step time window, number of particles ever crossing, used vs installed edges, first crossing iteration. Split B=0 must have exactly zero crossings. Full `full_union10` allows its actual many cross-parity edges; no fabricated edge weights.
- For every dataset×seed×arm, demand exact **bitwise equality between observed and ordinary same-graph fits** on all six full final state arrays, original native stopping metadata, *all five global MT19937 RNG fields* and the next 16 generated uniform draws; independently check true raw low-level ownership final snapshot vs high-level normalized ownership. Demand exactly 100001 unique real iteration callbacks 0..100000 with one additional metadata notification, no observer replay or intervention.
- Report per-dataset, per-seed, per-arm accuracies on exactly the same initially unlabeled mask within condition, plus accuracy by parity side and signed paired differences (B1−B0, B8−B0, B32−B0, full−B0). Include *individual seed outcomes*, worst observed losses, mean of paired differences and movement/crossing statistics. The five graph arms can consume different random-number streams after graph-degree changes despite identical integer initial seeds; **RNG parity applies only within observed vs ordinary same-graph pairs**.
- Synthetic checks: graph nesting at all doses, exact cross-edge list, partition class coverage, no self-loops/isolates, exact B counts and SHA fingerprints, no illegal physical crossings and out-and-back crossing visibility, skipped callbacks rejected. Strict aggregate must reject missing/duplicate/partial dataset×seed×arm cases; verify original graph, seed and labeling metadata, class-window counts 2×100 or 3×100 as applicable, crossing totals, edge counts, distribution by class/particle/window and exact baseline/state parity. Archive complete per-job JSON and environment freezes, with a separate human-readable summary.

## Prespecified interpretation restrictions
