# Frozen protocol: labeled-home degree selection on *unaltered canonical undirected graphs*

**Registered before any outcome from these new seeds and label strategies.** This is a new scientific study stacked on unmerged draft #187 (and #186–#182). No production implementation, graph, NumPy/Numba/Cython kernel, particle movement, particle strength, RNG, public API or potential-based stopping rules change; **do not merge**.

## Scientific question

Earlier undirected bridge experiments showed that traffic and accuracy are not interchangeable, and that changing a graph's artificial connectivity can influence classification without operational class immobility. This study moves to **the original production union-symmetrized kNN graph with NO edges removed or added** and asks how the **initial positions of labeled/home vertices** matter. It deliberately contrasts **local graph degree**, not global closeness, betweenness, graph periphery, active selection utility or an algorithmic bias correction. No claims that high degree implies centrality or that degree causes prediction accuracy.

## Frozen cohort, graph and three initially labeled masks

- Exactly three independent sklearn datasets, **Digits (1797 vertices, 10 classes)**, **Wine (178 vertices, 3 classes)**, **Breast Cancer (569 vertices, 2 classes)**. Standardize *whole data* via `StandardScaler` as previous canonical PyPCC studies. Construct **one and only one unchanged official `pcc_graph.build_knn_graph(X,k_nn=10)`** per dataset. Require reciprocal, loop-free, duplicate-free, minimum degree ≥10, **one connected component**, and a deterministic graph-edge SHA256 identical across label-selection conditions and independent seed jobs. Do not use artificial parity cuts, directed kNN, special reset, graph edge reweighting or any 'balanced neighbor' graph modification.
- Exactly **two initially labeled vertices per class** (**20/6/4 native particles**) in every arm, with 1777/172/565 initially unlabeled for evaluation. A **class-balanced oracle simulation** is required for *all three* strategies: training benchmark ground truth is used *only to determine eligibility for the labels and retrospective assessment*, never passed to the PCC algorithm beyond those explicitly selected labels. It is **not a deployable unlabeled-degree-only active selection algorithm**; selecting two low/high-degree examples per true class uses labels unknown in a typical SSL setting.
- Frozen seeds `(24103,24223,24317,24439)`, not used in #184–#187. For every dataset×seed use the identical official graph and per-class particle count in the following fixed three masks:
  1. **random**: from each ground-truth class uniformly choose two without replacement using a fresh independent `np.random.default_rng(seed)`, iterating classes 0→C−1.
  2. **low_degree_quartile**: for each class, rank its vertices by **ascending undirected production graph degree** and then by integer vertex ID (deterministic tie-breaking). Define the lower candidate pool as its first **max(2, ceil(class_size/4))** vertices; choose two uniformly without replacement, iterating classes in ascending ID with a **separate fresh `np.random.default_rng(seed)`**. Do not use outcomes to adjust this pool.
  3. **high_degree_quartile**: for each class, rank by **descending degree** and then by vertex ID; define the top candidate pool with the **same fixed max(2, ceil(class_size/4))**; independently choose two with a separate fresh `default_rng(seed)`. Rank ties remain ordered by vertex ID. Pool boundaries can include ties; this is a predetermined ranking, not a numerical quartile cutoff. Low/high candidate pools may share degree values but are disjoint *by vertex* if class size supports it.
- Freeze selection ordering `('random','low_degree_quartile','high_degree_quartile')`. Candidate pools, actual seed masks, mean selected and remaining degree, and labels per class are recorded. Require **selected vertices actually lie in their prescribed class-based pools** and exactly two homes per class. Selected vertex sets may overlap among arms accidentally, and equal outcomes are valid; do not exclude.
- In each true graph, record **actual selected mean/min/max degree** and, **retrospectively only**, true-label neighbor agreement fraction across *directed active neighbor entries of the selected labeled vertices* (homophily). These diagnostics reveal whether degree selection also changes proximity to class boundaries, but **never affect PCC inputs or candidate selection**. Record all selected vertex IDs and degrees, not just averages. Compare accuracies only on *the same initially unlabeled mask within an arm*, recognizing that **the masks differ across arms**: reported accuracy is on each arm's unlabeled complement, so direct percentage-point contrasts can have a small evaluation-subset difference. To eliminate that potential confound, also freeze the **common unlabeled intersection** across all three masks within dataset×seed, and compute **primary accuracy on that exact same common set for all arms**; secondary own-arm held-out accuracy is reported separately. Predetermined no labeled leakage on common set. **Primary paired Δ high−random and low−random** use the common set. Full seeded masks and common-mask counts must be archived.
- Use constant independent native sequential NumPy PCC settings `p_grd=.5,delta_v=.1,deltap=1,dexp=2,max_iter=100000,early_stop=False,es_chk=2000`. All conditions are fixed-cap, not proven converged. Same numeric seed across different masks does *not* ensure matched internal random tapes, because particles move differently; the exact-parity comparisons apply only between instrumented and ordinary fits **with the same graph AND same labels**.

## Native and measurement integrity (prespecified)

- **3 datasets × 4 seeds × 3 masks = 36 conditions**, with two independent full real native fits per condition (ordinary no-observer and one uninterrupted 100001-iteration-state experimental read-only observer), **72 real 100k fits**, 12 independent Python3.12/Linux dataset×seed jobs and required strict **36/36** aggregate summary. Alternate the order of ordinary/observed fits within a job.
- Reuse exactly the already audited `run_fit`, `MobilityObserver`, `verify_actual_final`, `rng_equal` from #184; **no changes to production or experimental NumPy callback**. The per-iteration stream records every real accepted particle move (including out-and-back), per-particle longest stillness, zero whole-system movement steps, per-class moves, maximum/minimum strengths, winning outgoing neighbor entries, and dominance mass across 100 nonoverlapping 1000-iteration windows per class.
- Reuse unchanged operational class-lockout criterion from #184–#187: **5 consecutive 1000-step class windows with zero accepted movements, max particle strength ≤0.01 and zero winning outgoing neighbor entries**. A zero-acceptance window/lockout is an observation, not a build failure or proof of permanent trapping. Report events and any recoveries. Do not introduce force floors, resets, teleportation or reset counters.
- Exact checks in every instrumented vs ordinary **same-label, same-graph** pair: **six full final arrays bitwise equal**, original native stop metadata equal, all five global MT19937 state fields equal and next 16 draws equal, actual low-level final state including *raw ownership before normalization* equal, exactly 100001 distinct 0..100000 real iteration callbacks plus one final info notification. Reject any incomplete or partially recovered dataset×seed×strategy sample.
- Raw JSON must record the frozen graph-edge fingerprint, class pool IDs/rank sizes, 3×label selections, both primary common-unlabeled and per-arm own-unlabeled accuracies, 1000 per-class windows per 10-class Digits run (or 300/200 for Wine/BC), full RNG/low-level parity flags, per-particle mobility and environment dependencies; CI summary must require 3 datasets×4 seeds×3 strategies exactly once, detect any unexpected topology or labels/accuracy/common-mask invalidity, and compute primary **per-dataset/seed differences on the same evaluation examples**. Unit tests check degree sorting/ties, class-quartile eligibility, fixed seed determinism, common-held-out intersection, graph connectivity and no observer side effects.

## Interpretation limits and decisions

This is an **oracle class-balanced stress test**, not a proposed active-learning strategy feasible without class labels. A graph degree bias is not necessarily structural centrality and can correlate with many uncontrolled characteristics (sample density, class margin, class size, neighbor quality). **Primary comparison fixes the evaluation set but not the labeled training set**, which is precisely the intervention of interest; stochastic trajectories vary as an expected consequence. Four independent seeds in one dataset per strategy cannot establish statistical equivalence, population prevalence, general benefit, or a recommended default. No branch is merged, no production stop, graph build, particle reset, degree-based sampling feature, or hyperparameter is recommended solely on this exploratory cohort. Any future intervention would require further independent prospective validation.
