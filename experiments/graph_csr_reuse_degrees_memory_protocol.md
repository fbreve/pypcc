## One frozen new candidate

In both original CSR-to-dense ordered neighbor-list scatter blocks of `pcc_graph.py`:

1. **Eliminate redundant degree array:** replace `degrees = (adj.indptr[1:] - adj.indptr[:-1]).astype(np.int64)` (and `degrees2`) with **`degrees = neib_qt`** (respectively `degrees2 = neib_qt`). This prevents a second full `int64[n_nodes]` vector allocation when the original `neib_qt = np.diff(adj.indptr).astype(np.int64)` already has exactly those integer values. No mutation of `neib_qt` is permitted.
2. In both CSR scatters only, retain SciPy's native safe index widths for full-`nnz` **temporary** index vectors: `row_idx = np.repeat(np.arange(n_nodes,dtype=adj.indices.dtype),degrees)`; `col_idx = np.arange(adj.indices.size,dtype=adj.indptr.dtype) - np.repeat(adj.indptr[:-1],degrees)` (and corresponding `num_nodes/degrees2`). Assignment into the **unchanged public padded `int64` neighbor-list** uses `adj.indices` directly without allocating a complete temporary `int64` RHS. When SciPy needs `int64` CSR indices, both temporary index vectors automatically remain `int64`; no unconditional narrowing to `int32`.

No other changes. Preserve full public `int64` graph arrays and shape/padding, CSR neighbor order, symmetrization, duplicates, loops, invalid-input behavior, kNN `algorithm='auto'`, graph topology, all PCC kernels, RNG, early-stopping and packaging. Refuse integration if any output differs or any downstream original-backend state diverges. This V2 is a *different combined allocation approach* rather than a post-hoc threshold for conditionally enabling V1. **No size-based special case, adaptive cutoff or dataset-name dispatch** may be learned from V1 results.
