# PyPCC v1.4.0

PyPCC v1.4.0 consolidates the production improvements made since
[v1.3.0](https://github.com/fbreve/pypcc/releases/tag/v1.3.0),
including faster graph and initialization paths, improvements to the compiled
backends, reproducibility controls, input validation, regression coverage,
and installable package metadata.

## Highlights

- **Reproducible fits:** optional `seed` argument to `fit_predict` for
  NumPy, Numba, and Cython. Replays are designed to be repeatable **within
  the same backend**; backends use different RNGs and are **not** guaranteed
  to produce identical sequences or outputs.
- **Faster preparation:** optimized ordered CSR-to-dense neighbor conversion,
  reused graph-construction buffers, skipped unnecessary diagonal cleanup when
  the input is known to be loop-free, accelerated validation and class-label
  mapping. The padded dense neighbor representation is deliberately retained.
- **Compiled-backend improvements:** Cython stopping/potential-cache
  optimizations, including canonical cache initialization; persistent Numba
  JIT cache across fresh Python processes and less redundant work in fit
  postprocessing.
- **More robust API:** additional graph, label and direct-kernel validation,
  numerical boundary checks, and safeguards against leaving partially updated
  fitted state after a failed operation. RNG state is **not** rolled back on
  failed fits if a backend already consumed random numbers.
- **Additional experimental mode:** an explicitly selected NumPy synchronous
  update mode, distinct from the default sequential PCC algorithm.
- **Verification and documentation:** extensive deterministic regression,
  backend-state/invariant and packaging tests, clearer README and contributor
  documentation, and preserved experimental research provenance.

## Installation and compatibility

The distribution is named **`pcc_step`**; the public library is imported
with `from pcc import ParticleCompetitionAndCooperation`.

- Requires **Python 3.10 or newer**, **NumPy 2.x**, SciPy and scikit-learn.
  Numba remains an optional backend dependency.
- The Cython extension is built from source using Cython and a suitable C
  compiler. Packaging uses `pyproject.toml`, an explicit `VERSION` file,
  and the MIT license.
- The regression CI matrix covers **Windows and Linux with Python 3.10 and
  3.12**; other Python versions and macOS are not asserted tested.

The declared Python/runtime dependency requirements should be reviewed
when upgrading from older installations. When possible, use a clean virtual
environment rather than installing over an old one.

```sh
python -m pip install -e ".[numba]"
```

`impl="auto"` still selects the first available backend in the order
Cython, Numba, NumPy; it does not benchmark them. The default PCC update
mode remains sequential.

## Scope

This release packages only changes already merged into the production
`master` prior to its release-preparation branch. Open research/draft PRs,
including the P2 observation/checkpoint and 72-fit scientific study
infrastructure, are **not** included. Historical scientific archives
published as separate GitHub Releases are independent of this software
version.
